# Figures

Generated manuscript figures belong here.

Canonical manuscript-facing filenames should use sequential descriptive names, for example:

- `figure1_decision_architecture.pdf`
- `figure2_expected_loss_phase.pdf`
- `figure3_evidence_policy_comparison.pdf`
- `figure4_empirical_delta_q.pdf`
- `figure5_ptbxl_policy_comparison.pdf`

Supplementary figures should use `figureS1_...`, `figureS2_...`, etc.

Each figure should be regenerated from code and machine-readable results. Avoid manual editing of numerical annotations after export.
