# Empirical results

This directory contains the locked held-out empirical record for Challenge 2015 and PTB-XL 1.0.3. Neither gate achieved `q1>q0`; both reduced PPV.

Primary files include candidate counts, main metrics, bootstrap intervals, strategy controls, threshold-equivalence diagnostics, the fixed cost grid, transport strata, dataset characteristics, artifact manifests, consistency audit, and frozen run metadata.

The source datasets are not redistributed. See `data/README.md` for provenance and full-reconstruction instructions.
