# General Admissibility Gating Law

Reproducibility package for candidate-conditioned evaluation of post-positive gating in biomedical decision systems.

This repository is intentionally a **computational archive**, not a mirror of the manuscript. The Overleaf/LaTeX source is maintained separately. The public release contains the minimum material needed to regenerate the manuscript-facing figures, inspect the frozen empirical record, and verify the principal numerical identities and held-out results.

## Core quantities

For a fixed detector `P` and downstream gate `Q`:

- `q1 = Pr(Q=1 | P=1, T=1)` is true-candidate retention;
- `q0 = Pr(Q=1 | P=1, T=0)` is false-candidate retention;
- `Delta_Q = q1 - q0` is candidate-conditioned gate discrimination.

For a nondegenerate fixed detector, PPV increases if and only if `q1 > q0`. Expected loss follows a separate prevalence- and cost-weighted criterion.

## Reproduce the manuscript figures

From the repository root:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/reproduce_figures.py
```

This regenerates the deterministic simulation outputs with seed `20260809`, combines them with the locked aggregate empirical results in `results/empirical/`, and writes the eight canonical vector PDFs to `figures/`.

The biomedical source datasets are **not required** for this figure-reproduction path and are not redistributed.

## Verify the frozen record

```bash
python -m unittest discover -s tests -v
python scripts/check_theory.py
python scripts/audit_empirical_results.py
```

The repository also preserves `results/empirical/consistency_audit.json`, the read-only audit produced at evidence freeze. That audit records 39 numerical reconstruction checks and 28 artifact/source checks at tolerance `1e-12`, with no failures. The complete development environment recorded 34/34 passing tests before evidence closure.

## Frozen empirical results

The held-out analyses use:

1. PhysioNet/Computing in Cardiology Challenge 2015, version 1.0.0;
2. PTB-XL, version 1.0.3.

Hidden Challenge test labels were not used. The repository contains only aggregate/machine-readable outputs needed for the reported figures and checks. See `data/README.md` for dataset provenance.

## Repository layout

- `src/` — analytical, simulation, and empirical evaluation modules.
- `scripts/` — simulation, figure-generation, theory-check, audit, and acquisition helpers.
- `results/empirical/` — frozen held-out aggregate outputs.
- `results/simulations/` — deterministic outputs regenerated by `scripts/run_simulations.py`.
- `figures/` — generated canonical PDFs; these need not be version-controlled.
- `tests/` — public numerical and implementation checks.
- `theory/` — supporting notation and derivation notes when included in the release.
- `data/README.md` — authoritative dataset provenance; no raw records are redistributed.
- `docs/` — evidence-freeze and reproducibility documentation.

## Scope of the archive

The guaranteed public reproduction target is the manuscript-facing numerical record and figures. The repository does not contain raw PhysioNet records, private data, or the manuscript LaTeX source. The original datasets remain subject to their provider terms.
