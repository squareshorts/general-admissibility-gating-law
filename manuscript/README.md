# Manuscript

This directory is reserved for the exact manuscript source associated with a tagged release.

The current working manuscript should be copied here only after the JBI-facing text, figure calls, table layout, data/code statement, author metadata, and supplementary-material references are synchronized with the final Overleaf version.

Recommended release file:

- `main_JBI.tex`

Do not commit a stale manuscript snapshot simply to populate this directory.
